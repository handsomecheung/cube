# Release Notes - v0.1.6 (2026-07-16)

This release introduces direct content/string encoding support in both the CLI and library API, adds C-API (FFI) bindings for decoding, provides a text display area in the web scanner, and integrates GitNexus AI developer workflow guidelines.

## What's New

### 🚀 Features
- **Direct String Content Encoding**: Added support for encoding raw string content directly, rather than just files.
  - Added `--content` (`-c`) and `--file` (`-f`) options to the `fountain-encode` CLI while maintaining backward compatibility with the existing positional arguments.
  - Added library functions `encode_data_for_terminal`, `encode_data_to_gif`, and `encode_data_to_images` to allow encoding from raw bytes/strings.
  - When the filename is empty (such as in direct content mode), the decoded output in the CLI defaults to saving as `decoded_content.txt`.
- **C-API (FFI) Bindings for Decoding**: Added foreign function interface (FFI) support for decoding.
  - New FFI decoder API functions exposed from Rust (`src/ffi.rs`):
    - `fountain_decoder_create` / `fountain_decoder_free`
    - `fountain_decoder_feed` (supports Base45 decoding and RaptorQ reconstruction progress tracking)
    - `fountain_decoder_get_filename` / `fountain_free_string`
    - `fountain_decoder_get_data_size`
    - `fountain_decoder_copy_data`
- **Web Scanner Text Display**: Added a dedicated text display area (`content-display-area`) in the Web scanner UI (`www/index.html`) to display decoded content strings directly on the web app.

### 📝 Documentation & Tooling
- **C-API Usage Guide**: Updated `README.md` with complete details, descriptions, and function signatures of the FFI decoder functions.
- **GitNexus Instructions**: Added GitNexus skills guides under `.claude/skills/gitnexus/` for various developer tasks:
  - `gitnexus-cli`
  - `gitnexus-debugging`
  - `gitnexus-exploring`
  - `gitnexus-guide`
  - `gitnexus-impact-analysis`
  - `gitnexus-refactoring`
- **Documentation Updates**: Updated developer agent contextual documentation in `AGENTS-CONTEXT.md`, `CLAUDE.md`, and `GEMINI.md`.

### ⚙️ Dependencies
- Updated and pinned Wasm-related dependencies (`wasm-bindgen`, `js-sys`, and `web-sys`) in `Cargo.toml`.

### 🧪 Testing
- Added integration test `test_encode_decode_content_roundtrip` in `tests/integration_test.rs` to verify encoding and decoding of raw text content.
